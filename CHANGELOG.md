# Changelog

All notable releases of the Professional Site are documented here.

## [0.2.0] — 2026-08-24

### Added

- Added the typed professional content structure and evidence-aware content foundation.
- Added the Home, Professional Summary, Experience, Resume, and Contact experiences.
- Added the career timeline and professional identity content.
- Added accessible contact links and navigation validation.
- Completed the core professional experience and shared styling foundation.

## [0.1.0] — 2026-08-12

### Added

- Established the React and strict TypeScript application foundation.
- Added the semantic application shell, MVP routes, and responsive keyboard-accessible navigation.
- Added baseline styling, accessibility validation, component tests, and end-to-end testing.
- Added the initial CI quality gate and Cloudflare Pages deployment foundation.
- Prepared the project for its first production deployment.
